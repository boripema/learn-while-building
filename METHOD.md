# Legacy prompt method

The prompt-injected Learn blocks and quizzes have been retired. No configured hook loads this file. The visual companion's current design, installation and limitations are documented in README.md and vscode/README.md.

The four goals remain code quality, development speed, product understanding and transferable software knowledge. The user's additional-token ceiling is 5% across whole tasks; this alpha has not established that causal measurement. The local viewer/indexer make no model calls or teaching prompt injections. Neither viewing a diagram nor passing finite exercise tests establishes mastery.
